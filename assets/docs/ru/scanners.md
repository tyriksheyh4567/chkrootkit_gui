# Параметры сканеров и каталоги

Проверено по документации проектов; установленные версии могут отличаться.
Ниже перечислены фиксированные аргументы, которые передаёт приложение.

| Утилита | Аргументы проверки | Что меняет рабочий каталог |
| --- | --- | --- |
| chkrootkit | стандартные проверки; `-r <корень>` при выборе другого каталога | Ищет помощников через относительные пути (`./strings-static`, `./chkproc` и др.). Нужен полный каталог поставки. |
| rkhunter | `--check --skip-keypress --report-warnings-only --nocolors` | Cwd процесса; конфигурация/базы остаются по правилам установленного rkhunter. |
| unhide (Linux) | `-u -H quick` | Cwd процесса. `quick` проверяет процессы, `-u` отключает буферизацию, `-H` делает результат понятнее. Проверка портов — отдельный unhide-tcp. |
| Lynis | `audit system --quick --no-colors` | Каталог standalone-комплекта может использоваться для include-файлов; пакетная установка использует системные пути. `--quick` совместим со старыми выпусками; в 3.x неинтерактивный режим уже стандартный. |

Для версий используются `chkrootkit -V`, `unhide -V`, для остальных — `--version`.
Ошибка получения версии без root не прерывает проверку доступности остальных утилит.
На машине разработки обнаружены chkrootkit 0.59 и Unhide 20240509; rkhunter
ограничивает доступ для непривилегированного пользователя. Для самой проверки требуются права root.

## Каталог сканирования и рабочая папка

Пустое поле cwd выбирает каталог реального бинарника после разрешения ссылок.
Например, ссылка `/usr/bin/chkrootkit` → `/usr/lib/chkrootkit/chkrootkit` даёт cwd
`/usr/lib/chkrootkit`. Путь с пробелами передаётся как путь, без shell-экранирования.
Явный абсолютный каталог валидируется сервисом с правами root перед запуском.
Несуществующая папка выдаёт ошибку, без молчаливого перехода в другой каталог.

`chkrootkit -r /mnt` задаёт другой корень файловой системы, а `-p` — поиск доверенных
системных команд. Ни тот, ни другой аргумент не заменяет cwd с помощниками.
В Unhide смена cwd не переключает сканирование `/proc` на другой диск. Для Lynis
проверка альтернативного rootfs не эквивалентна изменению cwd: upstream отмечает,
что поддержка альтернативного корня не охватывает все тесты. В приложении выбор каталога сканирования передаёт `-r` только chkrootkit. Остальные утилиты проверяют работающую систему. В современных rkhunter прежний rootdir удалён.

## Права и seatd

Для chkrootkit/rkhunter/unhide приложение требует root через pkexec независимо
от места установки. Lynis допускает ограниченный аудит без root; полноценный
аудит предпочтительно выполнять с root. Полный архив поставки не следует
заменять одиночным скриптом в `.local/bin`.

seatd/libseat обслуживает доступ композитора к устройствам. Он не является
заменой polkit, агента аутентификации или pkexec, и не требует иного варианта
утилит повышения прав.
