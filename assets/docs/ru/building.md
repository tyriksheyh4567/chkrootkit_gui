# Сборка и выпуск

Для сборки нужен Linux, Flutter 3.47.1 с Dart 3.13.1 или совместимый SDK, CMake, Ninja, C++17-компилятор и библиотеки разработки GTK 3. Зависимости Python нужны только для TUI.

- `make tui` или `./build.sh` — открыть менеджер сборки. При первом запуске создаётся `.venv-tui` и устанавливается Textual 8.2.8. Нужен Python 3.10+ с venv и pip.
- `make build` — собрать приложение и сервис в release.
- `make service` — собрать только C++-сервис.
- `make package FORMAT=deb` — собрать и упаковать приложение. Доступны `rpm`, `appimage`, `pkg.tar.zst`, `all`.
- `make build FLUTTER=/путь/flutter MODE=debug JOBS=4` — переопределить параметры.

TUI показывает цель, режим, формат, параллельность и пути, проверяет параметры, выводит журнал и позволяет остановить сборку. Tab переключает фокус, Ctrl+B запускает сборку, Ctrl+K отменяет, Ctrl+Q закрывает менеджер. Дополнительные поля доступны прокруткой формы.

Командный интерфейс `./build.sh --help` подходит для автоматизации. `--bundle-dir` упаковывает уже готовый bundle. Сборщик проверяет наличие `dpkg-deb`, `rpmbuild`, `bsdtar`/`zstd` и `appimagetool` для выбранных форматов. AppImage использует системные GTK, polkit и SQLite; переносимость зависит от окружения.

GitHub Actions запускается вручную через **Actions → Release → Run workflow**. Версия должна совпадать с `pubspec.yaml` и разделом `CHANGELOG.md`. Публикация включается отдельным параметром; по умолчанию результаты доступны как артефакты. Описание релиза берётся из журнала изменений. Перед публичным выпуском проверьте пакеты на целевых дистрибутивах.
