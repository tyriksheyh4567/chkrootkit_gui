# Хранение данных

Настройки API расположены в `$XDG_CONFIG_HOME/chkrootkit_gui/api.db` (по умолчанию `~/.config/chkrootkit_gui/api.db`). Кэш ответов хранится отдельно: `$XDG_CACHE_HOME/chkrootkit_gui/requests.db` (по умолчанию `~/.cache/chkrootkit_gui/requests.db`). Оформление и язык записываются в `appearance.json` без шифрования.

Содержимое API-профиля и ответы в кэше зашифрованы AES-256-GCM. Ключ получается из пароля с помощью PBKDF2-HMAC-SHA256, 210 000 итераций и случайной соли. Пароль и производный ключ не записываются на диск. Структура SQLite, соль, метаданные проверки, хэши и время кэша остаются видимыми; шифруется содержимое записей.

API-ключ сохраняется только при включённой опции. В кэше остаётся до 100 ответов на срок до семи дней. Исходные логи и API-ключи в кэш не записываются. Экспортированный `.log` содержит обычный текст — храните его с учётом конфиденциальности.

Диалог зависит от состояния хранилища: создание нового пароля, разблокировка, шифрование старых записей или сообщение о повреждённых базах. Повреждённые базы автоматически не заменяются. Перед ручным восстановлением сделайте резервную копию.

**Удалить обе базы…** требует подтверждения и удаляет профили, ключи, кэш и параметры шифрования вместе с файлами SQLite WAL/SHM/journal. Экспортированные логи сохраняются. Операция не гарантирует физическое стирание копий, резервных снимков и блоков SSD. Потерянный пароль восстановить через приложение невозможно.
